🔍 gospect-mcp

A Go-only, report-first code scanner. It runs the real Go toolchain over your code and reports genuine bugs — as an MCP server or a CLI. It never edits your code.

Go 1.21+ MCP server + CLI No LLM in the server Report-first
GitHub → Install

Why gospect-mcp

Ask an AI assistant to “find bugs” and roughly one in fifteen is a real defect — the rest are confident guesses. gospect-mcp is the opposite: a deterministic sensor that is certain about a small set of things and hands the judgment back to you.

Report-first

The output is a report. It never touches your code — fixes are a separate, explicitly-invoked step.

Sensor, not oracle

Pure Go tooling (go/packages, go/analysis, SSA). No LLM in the server — your MCP host supplies the intelligence.

Genuine over noisy

Semantically-backed findings, not grep guesses. Generated code is skipped automatically; noise is suppressible per-line and repo-wide.

Monorepo-native

Point it at the repo root — every nested go.mod is discovered and scanned in one run.

Install

One-line install (macOS / Linux)

curl -fsSL https://raw.githubusercontent.com/backendArchitect/gospect-mcp/main/install.sh | bash

Windows (PowerShell)

irm https://raw.githubusercontent.com/backendArchitect/gospect-mcp/main/install.ps1 | iex

With Go

go install github.com/backendArchitect/gospect-mcp@latest

Prebuilt binaries

Linux / macOS / Windows, amd64 & arm64 — Releases page.

Then scan

gospect-mcp scan /path/to/your/module ./...

Findings come out as JSON, ordered by importance — bugs first. Run gospect-mcp help for every command and flag.

Performance

gospect builds on the Go type-checker, so it’s bounded by go build, not by the tool. Warm-cache, single machine:

ScopePackagesTimeNotes
Single small module~12~1sthis repo
Mid-size module272~2.5sload 2.1s / scan 0.5s
Full 9-module monorepo458~30sone command, all services

The first scan of a big repo is slower while Go compiles its dependencies once; subsequent scans are fast. Scope with a package pattern for instant results.

Works with any AI agent

gospect speaks the Model Context Protocol over stdio, so any MCP client can use it. And because every scan is stateless, you can point as many agents at it as you like — there’s nothing to coordinate.

Claude Code

claude mcp add gospect gospect-mcp

Any MCP client (Cursor, Windsurf, Cline, VS Code, Zed, …)

{
  "mcpServers": {
    "gospect": { "command": "gospect-mcp", "args": [] }
  }
}

Report-only means an agent cannot change your code through gospect — only surface findings and, on request, a fix envelope.

In CI

gospect-mcp check -fail-on high .                   # exit non-zero on any high-severity bug
gospect-mcp scan -format sarif . > gospect.sarif    # SARIF for GitHub code scanning
gospect-mcp scan -vuln .                            # optional: govulncheck for known-CVE deps

A drop-in GitHub Action can upload SARIF so findings appear as inline PR annotations. Baseline mode (-baseline) lets you gate only on new findings, so you can adopt gospect on a repo that already has hundreds.
